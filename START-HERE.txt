Changes review — 1 November 2026

Open View > Changes review to compare the working PDF with its originally opened copy. Changed pages are marked in the page strip and page headings. Previous/Next and the page list navigate modified, added, removed and moved pages. Toggle Original/Current for read-only page previews or open the larger comparison. Retained edits have individual before/after views without restoring earlier versions. Save PDF > Export review also offers Review page changes before downloading; this returns to the panel without downloading until Save is chosen again.

Text-fit/reflow choices (feature 4) remain in Edit > Direct edit: Keep layout, Fit text into box, and Move following text in this column. Recognition buttons now use a pastel red background with visible hover/focus states.

Review is local and does not change document bytes or history. It checks rendered pages, text geometry, form values, comments and links; tiny visual differences and hidden PDF structures may need separate inspection. Page matching uses contents; repeated identical pages are paired by position. Undo history is bounded to 20 steps, and undone edits are excluded from retained edits. The original baseline survives local recovery.

PDFCreator — live previews, OCR review, groups and text layout — 1 November 2026

Text boxes: in Edit > Select objects, resizing native text, added text and FreeText comments changes the container and wrapping without scaling font sizes. Boxes grow downward when needed, and Direct edit keeps the chosen width as words are added. Added text defaults to automatic growth; Fit text remains an explicit sizing choice. Mixed groups scale artwork while retaining text sizes. Growth that affects nearby content requires confirmation, and page-edge overflow requires moving or widening the box.

Text-box sizing checks: text-box-sizing-ui-test.mjs, 68 assertions in source and compiled app: fixed run sizes, native/rich/comment wrapping, four page rotations, logical words, draft pixels, height growth, metadata/reopen, mixed groups, confirmation, page boundaries and exact Undo.

Open index.html in a current desktop browser. pdfcreator.html and the legacy
pdfpro.html are identical runnable aliases. Processing stays on this device.

Direct edit previews changes on the page while you type. Choose Keep layout,
Fit text, or Move following text in this column. Amber areas mark affected
content; purple areas mark moved text. Cancel discards the preview.

Expand Review recognised words and source boxes to correct OCR words and masks
or match estimated font appearance.

Select objects now supports rectangle selection, Group/Ungroup, alignment,
equal spacing and matching sizes. Groups persist when reopening in PDFCreator.

Edit > Direct edit can recognise outlined or scanned English text.
Click a recognised region to edit and replace its visible lettering.
For mixed/additional pages, choose Recognise text for editing on the page.
Review OCR words and estimated fonts/spacing before Apply. Undo is available.

In Edit > Select objects, Ctrl/Cmd-click or Shift-click to select a group on
one page. Move, resize, duplicate or delete them together. Object properties
uses a compact layout, with Back to Objects & layers in its header.

Drag the left edge of right-hand property panes or docked tool-settings
popups to resize them. Widths are remembered. Double-click resets a divider.

Direct edit shows formatting in the editable text box. Font, size, colour and
emphasis controls appear at the top. Select words to format them, or leave the
selection empty to format the whole block. Apply saves the edit to the PDF.

If formatting would overlap nearby text, choose Apply anyway in the
confirmation to proceed. Cancel keeps the draft. Undo reverses the edit.

Hide the helper bar with its × button. Restore it using the top three-dot menu
and Show helper bar. This preference is remembered on this device.

The embedded-font Unicode preservation fix and XLSX/CSV form generation remain
included. Previously corrupted PDFs still require Undo/History or an original
copy; this release does not guess at characters already lost from a PDF.
