CHANGES
- Paragraph (default), Line and Text chunk editing scopes. Paragraph/chunk edits
  reflow at a chosen width, closing gaps inside the selected text. Several paragraphs
  can be included in one dragged chunk, while unselected page content stays in place.
- Original font programmes, colours, sizes, first baseline and unchanged inline styles
  remain; changed words inherit source styles. Wrapping widths survive later edits.
- Inline/tool scope controls, draft protection, original-size wrapping, remembered
  scope and local recovery. Growth beyond the page or into other text is refused.
- Direct edit changes a visible PDF text run using its original native font data,
  colour, alpha, size and baseline. Compatible embedded fonts load locally for the
  typing preview; system/matching fallback fonts are used when unavailable.
- New app text boxes retain their appearance recipe for editing as a complete box.
  Missing source glyphs, overflow/overlap and unsupported encodings are refused.
  Scanned/outlined text, invisible OCR and legacy image-backed boxes are excluded.
- Document rebuilds restore the active page and both scroll offsets. The restored
  position is saved locally; subsequent intentional scrolling remains responsive.
- Visual signatures compose a typed name and drawing onto a separate transparent
  image, with the name below the drawing. Confirming no longer clears drawn strokes.
- Typed-only, drawn-only and standalone image import remain supported. Clear drawing
  preserves typed input. Pen taps, primary-pointer ownership and release samples work.
- Combined PNG/PDF appearance, repeated placement, undo/redo and local recovery are
  checked. Empty input stays editable in the dialogue; cancelling retains prior state.
- The horizontal processing bar is replaced visually by a thin circular outline.
  Unknown progress traces the circumference; reported progress fills the ring and
  displays a percentage. Progress values are clamped to the valid 0-100% range.
- Job details, cancellation, completion/error cleanup and the labelled native
  progress element remain. Reduced-motion settings disable the looping trace.
- Native PDF link areas are exposed as clickable viewer anchors. External web/email
  links use normal browser handlers; internal page links jump within the document.
- Add link accepts URLs, email addresses and PDF-page destinations, validates inside
  its dialogue, and preserves placement mode until Done/same-tool deselection.

  rotation and nonzero origins; undo/redo and local recovery retain PDF link data.
- Disallowed imported URI schemes never become browser hrefs. Native mutation
  buffers are freed after copying output bytes.
- OCR words on a line share their baseline/size. Plain-text extraction uses line
  grouping instead of preserve-spans, avoiding spurious line breaks between words.

  UI workflows exercise page tools, forms, OCR, comparison, protection, signing,
  every export type, all batch operations and a controlled print request.

  navigation and on-demand local rasterisation. Fixed-size page slots avoid jumps

SCOPE AND RETENTION
Recovery is stored in the browser profile/origin when IndexedDB is available. Quota,
private browsing, browser eviction, clearing site data or changing origin can affect it.
file:// compatibility is browser-dependent and indicated by the app save status.
Local working copies may be unlocked and retain original/undo content after redacted
exports; remove closed copies from Library when appropriate. Download PDFs/workspaces
for backup or transfer. Certificate passwords and signing keys are not persisted.
The application remains an offline PDF toolkit with README.txt limitations; it does
not claim complete Acrobat parity or standards/certificate-trust certification.
