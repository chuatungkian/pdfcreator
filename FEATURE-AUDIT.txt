RESULT
74 distinct tool actions are mapped below to passing regression workflows.
The functional baseline passed 1,270 counted assertions plus certificate-signing
and actual-package integrity checks. The later circular-indicator presentation
update reran 165 targeted workflow/continuous-page/source-export assertions plus
syntax and package-integrity checks. The visual-signature fix then passed 281
targeted composition/placement/font/workflow/source-export assertions and a native
PDF rendering inspection. The Direct edit/view-retention revision adds 576 native and controlled-interaction
assertions, with original-font glyphs checked against independent PDF renders.
Existing affected font/placement/scroll/signature/link/persistence/drawing/workflow
suites were rerun. The paragraph/chunk reflow revision then adds 188 native PDF
and controlled UI assertions, with affected Direct edit/layout/storage suites rerun.
The PDFCreator rename then passed 30 branding/workspace/recovery checks, with
affected PDF/UI suites and release/source integrity checks rerun.
Native form widgets are directly editable with multiline text/formatting, shared field values and appearances retained. See form-fields-test.mjs and form-fields-interactions-test.mjs. Large-image soft-mask memory growth no longer invalidates image colour buffers; see image-memory-test.mjs. Independent cm page decoration offsets are checked in page-placement-test.mjs.
Existing and added images have crop, position/size and appearance controls with instance-local native editing. Clicking grey non-working space deselects the active tool. See image-edit-test.mjs and image-interactions-test.mjs.
Home project cards now have a confirmation-protected dustbin; serialised deletion prevents autosave resurrection. See home-deletion-test.mjs.
The magnifying-glass app search indexes all tools and opens their existing workflows. See function-search-test.mjs.
Navigation functions toggle their popups on repeated clicks; see navigation-toggle-test.mjs.
Create now uses the shared side tool pane with three actions; there is no central Create choice dialogue. Its document/import checks are in create-interactions-test.mjs.
The compression revision adds size-aware Save PDF and non-flattening image recompression with target-size search, result confirmation and undo. See compression-test.mjs and compression-interactions-test.mjs.
The current revision adds independent page-band alignment/rules/timestamps, object/new-text links, compact tool popups and direct thumbnail organisation. See page-features-test.mjs and page-strip-test.mjs.
The completion revision adds object transforms, rich text, text-aware markup, all-page comments, a visual organiser and document-wide find/replace. See VALIDATION.txt for current counts. Live browser dialogue/animation remains unverified.
This is a scoped automated audit, not a certification that every possible PDF,
device or browser behaviour is supported.

FIXES
- The app, canonical package names and source downloads use PDFCreator. Legacy
  local storage, API/metadata keys, .pdfpro workspace imports and the pdfpro.html
  compatibility path remain usable. New workspaces use .pdfcreator.
- Direct edit offers Paragraph (default), Line and dragged Text chunk scopes.
  Paragraph/chunk text rewraps at the chosen width, closing gaps inside the selected
  flow. Source font programmes, colours, sizes and unchanged inline styles remain.
- Inline/tool scope controls, wrapping width, draft protection and remembered scope
  accompany gap closing, original-width retention, undo/redo and local recovery.
  Flow stays on one page and avoids unselected text; scanned/outlined text is excluded.
- Direct edit opens an on-page editor for visible PDF text runs, retaining their
  source font programme, colour, alpha, size and baseline. New PDFCreator text boxes
  retain their system-font recipe; compatible embedded fonts load locally for typing.
- Missing glyphs, overflowing replacements and unsupported encodings are refused.
  Scanned/outlined text and older image-backed boxes cannot be edited directly.
- Document rebuilds restore the current page and both scroll offsets after edits,
  insertions and undo/redo, including simulated browser layout clamping.
- Typed names and drawn signatures are combined without erasing the drawing, with
  the typed name underneath. Standalone modes, clear/import, undo/redo and local
  recovery remain supported.
- Processing now uses a circular outline: unknown work traces the circumference,
  while reported progress fills the ring and shows its percentage. Cancel, task
  details, native progress semantics and reduced-motion preferences are retained.
- Created and imported PDF links now have clickable areas in the viewer.
- Add link validates inside its dialogue and accepts website/email destinations
  or a page in the same PDF. Link bounds survive rotation and nonzero page origins.
- Done/same-tool deselection enables following links. The link arrow edits/removes
  the destination; undo/redo and browser-local recovery retain native PDF links.
- Disallowed imported URI schemes never become browser navigation targets.
- OCR words on one line share a baseline/size. Plain-text extraction no longer
  forces font spans onto separate lines; phrase search and text export are checked.
- Native PDF mutation buffers are released immediately after bytes are copied.

OTHER WORKSPACE CHECKS
- Create: configured blank PDFs, existing PDF tabs and optional native Microsoft Word imports.
  See create-interactions-test.mjs and word-companion-test.mjs for current checks.
- Continuous scrolling, lazy rendering, active-page/toolbar/thumbnail synchronisation,
  mixed page dimensions/rotations, page jumps, zoom anchoring and gesture ownership.
- Tabs, Home/Resume, duplicate filenames, font choices/appearances, compact previews,
  tool persistence, drawer/dock navigation, dark theme and movable page controls.
- IndexedDB atomic writes, recovery, original/history retention, quota failures,
  revision conflicts, closed-library copies and invalid stored-document isolation.
- Embedded PDF worker methods and real English OCR core/model run offline in a
  controlled Node VM worker transport with native canvas. No network requests occur.
- Downloaded PDF/text/JSON/image/ZIP contents are inspected. ZIP CRCs and names are
  independently decoded. Native signatures are checked with synthetic credentials.
- Actual HTML/bootstrap, source reconstruction, bundled worker/source identity,
  licences/notices, strict 25,000,000-byte HTML cap and release hashes are verified.

LIMITS OF THIS AUDIT
- UI actions run in jsdom with native PDF processing, simulated geometry and
  fake-indexeddb. This is not a live browser layout or actual browser profile.
- The app's file:// tab was previously blocked by browser-tool URL policy. No
  alternate browser route was used. User PDFs were never opened as test fixtures.
- External website/email navigation is represented by correctly targeted native
  anchors. Actual navigation handlers, browser download/save-picker behaviour and
  the operating-system print dialogue were not exercised in a live browser.
- Print builds real rendered page images and sends a print request to a controlled
  DOM popup. That does not validate pagination in a browser's print implementation.
- Worker adapters execute real bundled engines but do not prove browser Blob worker
  startup, process termination, content-security policies or file-origin support.
- Existing README limitations remain: English OCR and Latin search layer, bounded
  text replacement, widget flattening before page copying, certificate trust and
  standards limitations. There is no claim of complete Adobe Acrobat equivalence.
