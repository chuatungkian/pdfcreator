This rebuilt release adds live page previews, OCR correction/font matching,
object marquee/group/arrangement controls and fit/column text layout. The exact preferred
sources for this build are in pdfcreator-3.0-app-source.zip and embedded in the
HTML source download. All three HTML aliases contain identical bytes.

TEXT-UNICODE-FIX.patch documents the earlier font-mapping fix relative to
db29be13813be060d29a0cdfbaebc0c54ad354db. It is historical and does not represent
all changes in this release. The complete source kit already includes that fix
and the current UI changes. See GitHub history for the publishing commit.
